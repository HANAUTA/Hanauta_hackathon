# Antigravity CLI 利用ガイド

VS Code の中で AI と会話しながらコードを書く「バイブコーディング」をするためのツールです。
**無料**で使えます（個人の Google アカウントがあれば十分）。

> 💡 すでに自分の Claude Code が使える人（個人で契約している人）は、このページは不要です。
> [環境構築 ステップ4](02_環境構築.md#ステップ4aiコーディングツールを準備する任意) を参照してください。

---

## Antigravity CLI って何？

ターミナル上で使える AI 開発ツールです。開いているプロジェクトのコードを読んで、

- コードを説明する
- 新しい画面を作る
- 複数のファイルを編集する
- エラーの原因を調べて修正する
- 必要なコマンドを実行する

といったことを、日本語で指示するだけでやってくれます。

例：

```
投稿一覧画面を作りたいです。既存の構成をできるだけ壊さずに実装してください。
```

## 事前に必要なもの

- VS Code / Chrome / Git（[事前準備ガイド](01_事前準備ガイド.md)で用意済みのはず）
- **個人の Google アカウント**（Gmail など）
- 開発するプロジェクト（[環境構築](02_環境構築.md)で用意済みのはず）

## 1. インストールする

VS Code でターミナルを開き（メニューの「Terminal」→「New Terminal」）、OSに合わせて実行します。

### 🍎 Mac

```bash
curl -fsSL https://antigravity.google/cli/install.sh | bash
```

### 🪟 Windows

PowerShell で実行します。

```powershell
irm https://antigravity.google/cli/install.ps1 | iex
```

## 2. インストールできたか確認する

```bash
agy --version
```

バージョン番号（例：`1.x.x`）が表示されればOK。

> ⚠️ `agy: command not found` と出た場合
> 1. VS Code を完全に閉じて開き直す
> 2. 新しいターミナルを開いて `agy --version` をもう一度
>
> それでも動かない場合（Mac）、インストール時に PATH 追加の案内が表示されていないか確認してください。
>
> ```bash
> echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
> source ~/.zshrc
> ```

## 3. プロジェクトのフォルダで使う

Antigravity は「今いるフォルダ」をプロジェクトとして扱います。
[環境構築](02_環境構築.md)で作ったプロジェクトのフォルダに移動してから使ってください。

```bash
cd <プロジェクトのフォルダ名>
```

## 4. 使えるモデルを確認する

```bash
agy models
```

こんな一覧が表示されます（実際の内容は時期によって変わります）。

```
Gemini 3.5 Flash (Low)
Gemini 3.5 Flash (Medium)
Gemini 3.1 Pro (Low)
Claude Sonnet ...
...
```

## 5. 【重要】ハッカソンでは Gemini Flash を使う

**基本は Gemini Flash を使ってください。** 無料枠を長く使えるからです。
Gemini Pro は高性能ですが枠の消費が大きいので、最初から使うのはおすすめしません。

```
普段の開発            → Gemini Flash
どうしても解けない問題 → 必要なときだけ Gemini Pro
解決したら            → Flash に戻す
```

## 6. Flash を指定して起動する

`agy models` で確認した名前をそのまま使います。

```bash
agy --model "Gemini 3.5 Flash (Low)"
```

> ただ `agy` とだけ打っても起動できますが、意図せず別のモデルになる場合があります。
> ハッカソンでは **モデル名を明示して起動する** のがおすすめです。

## 7. 初回だけ Google アカウントでログインする

初めて起動すると、ログイン方法を聞かれます。

```
Select login method:
> 1. Google OAuth
  2. Use a Google Cloud project
```

**「1. Google OAuth」** を選んでください（↑↓で移動、Enterで決定）。

ブラウザが開くので、自分の Google アカウントでログイン → 認証を許可 → 表示されたコードをコピーして、
ターミナルに貼り付けて Enter。これで接続完了です。

## 8. 「このフォルダを信頼しますか？」

```
Do you trust the contents of this project?
> Yes, I trust this folder
  No, exit
```

自分たちのハッカソン用プロジェクトなら **「Yes, I trust this folder」** を選びます
（Antigravity にこのフォルダの読み書きを許可する、という意味です）。

## 使ってみる

起動できたら、まずはこれを送ってみましょう。

```
これからこのプロジェクトを使ってハッカソン開発をします。
まずプロジェクト全体を確認してください。

・私はプログラミング初心者です
・説明は簡単な日本語にしてください
・既存のコードをできるだけ壊さないでください
・大きな変更を一気にせず、小さく実装してください
・分からないことがあれば勝手に決めず質問してください
・コードを変更したら、何を変更したのか簡単に説明してください

まずはコードを変更せず、現在のプロジェクト構成を簡単に説明してください。
```

### 開発を進める例

```
投稿一覧画面を作ってください。

各投稿には次の内容を表示してください。
・ユーザー名
・画像
・本文
・いいねボタン

既存のプロジェクト構成をできるだけ壊さないでください。
```

### エラーが出たら

```
今エラーが出ています。原因を調べて、修正してください。
修正前に、何が原因だったのかも簡単に説明してください。
```

AI からエラー内容が見えていなさそうなら、エラー文をそのまま貼り付けます。

## よく使うコマンド

| コマンド | 効果 |
|---|---|
| `agy` | 起動 |
| `agy models` | 使えるモデルの一覧 |
| `agy --model "モデル名"` | モデルを指定して起動 |

起動中に使えるコマンド（先頭に `/`）：

| コマンド | 効果 |
|---|---|
| `/help` | ヘルプ |
| `/model` | 今使っているモデルを確認 |
| `/usage` | 残り利用枠を確認 |
| `/config` | 設定を開く |
| `/quit` | 終了 |

---

## 無料枠を使い切らないために

`/usage` でその週の残り枠を確認できます。

```
GEMINI MODELS
Weekly Limit Remaining
██████████████████░░
90% remaining
```

⚠️ **Gemini Flash と Gemini Pro は同じ枠を共有します。** Pro を大量に使うと、Flash で使える枠も減ります。

枠が減ってきたら：

- Gemini Flash を使っているか確認（`/model`）
- 同じ問題で何度も作り直させない
- 必要な部分だけピンポイントで修正してもらう

## 安全に使うためのルール

### AIに任せきりにしない

AI は間違ったコードを書いたり、必要な機能を消してしまうこともあります。

```
AIにお願いする → 変更内容を見る → アプリを動かす → 問題なければ次へ
```

### 一度に大きすぎるお願いをしない

「SNSアプリを全部完成させて」のような一気にお願いは、動いても後でエラーの原因が追えなくなりがちです。
小さく作って、小さく確認するのがコツです。

```
① 投稿一覧を作る → 動作確認 → ② 投稿作成画面を作る → 動作確認 → ③ デザインを整える
```

### 具体的にお願いする

| 悪い例 | 良い例 |
|---|---|
| いい感じにして | 投稿カードの角を丸くする／画像を横幅いっぱいにする／ユーザー名を太字にする |

### こまめに `git commit` する

大きな変更をお願いする前に、一度コミットしておくと、AI が壊してしまっても戻せます。

```bash
git add .
git commit -m "作業内容"
```

### 秘密情報を貼らない

APIキー・パスワード・個人情報などは、AIへの入力欄に貼らないでください。
「APIキーをコードに直接書いて」という実装も避けましょう（`.env` を使います）。

### ⚠️ このオプションは使わない

```bash
agy --dangerously-skip-permissions
```

AI が確認なしにファイル操作やコマンド実行を進めるモードです。**ハッカソンでは使用しないでください。**
通常の起動（Tool Permission が `request-review` のまま）なら、重要な操作の前に確認が入ります。

## 困ったときは

| 症状 | 対処 |
|---|---|
| `agy` が動かない | `agy --version` を確認。ダメなら VS Code を閉じて開き直す |
| 使えなくなった／応答が遅い | `/usage` で残り枠を確認 |
| 今どのモデルか分からない | `/model` で確認（画面右下にも表示されている） |
| Proになっている | `/quit` → `agy models` でFlashの正式名を確認 → `agy --model "その名前"` で再起動 |
| 操作方法が分からない | `/help` |
| それでも分からない | 運営に声をかけてください |

---

## ゴール

AI に全部やらせることが目的ではありません。**作りたいものを伝える → 動かす → 直す**、
というバイブコーディングの流れを体験することが目的です。まずは動くものを作ることを優先しましょう。
