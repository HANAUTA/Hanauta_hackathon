# Antigravity CLI 利用ガイド

VS Code の中で AI と会話しながらコードを書く「バイブコーディング」をするためのツールです。
**無料**で使えます（個人の Google アカウントがあれば十分）。

---

## 事前に必要なもの

- VS Code / Chrome / Git（[事前準備ガイド](01_事前準備ガイド.md)で用意済みのはず）
- **個人の Google アカウント**（Gmail など）
- 開発するプロジェクト（[環境構築](02_環境構築.md)で用意済みのはず）

---

## 1. インストールする

VS Code でターミナルを開き（メニューの「Terminal」→「New Terminal」）、OSに合わせて実行します。

### 🍎 Mac

```bash
curl -fsSL https://antigravity.google/cli/install.sh | bash
```

### 🪟 Windows

PowerShell で実行します。

```powershell
irm https://antigravity.google/cli/install.ps1 | iex
```

インストールできたか確認：

```bash
agy --version
```

バージョン番号（例：`1.x.x`）が表示されればOK。

> ⚠️ `agy: command not found` と出た場合
> 1. VS Code を完全に閉じて開き直す
> 2. 新しいターミナルを開いて `agy --version` をもう一度
>
> それでも動かない場合（Mac）：
>
> ```bash
> echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
> source ~/.zshrc
> ```

## 2. プロジェクトのフォルダで起動する

[環境構築](02_環境構築.md)で作ったプロジェクトのフォルダに移動してから使ってください。

```bash
cd <プロジェクトのフォルダ名>
```

**基本は Gemini Flash を使ってください。** 無料枠を長く使えるからです。
まず使えるモデル名を確認します。

```bash
agy models
```

一覧の中から Flash のモデル名（例：`Gemini 3.5 Flash (Low)`）を指定して起動します。

```bash
agy --model "Gemini 3.5 Flash (Low)"
```

> ただ `agy` とだけ打っても起動できますが、意図せず別のモデル（Pro）になる場合があるので、
> ハッカソンでは **モデル名を明示して起動する** のがおすすめです。

### 初回だけ：Google アカウントでログイン

```
Select login method:
> 1. Google OAuth
  2. Use a Google Cloud project
```

**「1. Google OAuth」** を選択（↑↓で移動、Enterで決定）。ブラウザが開くので、
自分の Google アカウントでログイン → 認証を許可 → 表示されたコードをターミナルに貼り付けて Enter。

### 初回だけ：フォルダの信頼確認

```
Do you trust the contents of this project?
> Yes, I trust this folder
  No, exit
```

自分たちのハッカソン用プロジェクトなら **「Yes, I trust this folder」** を選びます。

## 3. 使ってみる

起動できたら、まずはこれを送ってみましょう。

```
これからこのプロジェクトを使ってハッカソン開発をします。
まずプロジェクト全体を確認してください。

・私はプログラミング初心者です
・大きな変更を一気にせず、小さく実装してください
・分からないことがあれば勝手に決めず質問してください
・コードを変更したら、何を変更したのか簡単に説明してください

まずはコードを変更せず、現在のプロジェクト構成を簡単に説明してください。
```

開発をお願いするときは、具体的に伝えるのがコツです。

```
投稿一覧画面を作ってください。各投稿にはユーザー名・画像・本文・いいねボタンを表示してください。
既存のプロジェクト構成をできるだけ壊さないでください。
```

エラーが出たら、エラー文をそのまま貼り付けて聞けばOKです。

## Flutter アプリの実行は別のターミナルで

VS Code でもう1つターミナルを開いて（「Terminal」→「New Terminal」、または `+`）、そちらで実行します。

```bash
flutter pub get
flutter run -d chrome
```

```
VS Code
├── ターミナル①：Antigravity（AIと会話）
└── ターミナル②：Flutter（flutter run -d chrome）
```

## よく使うコマンド

| コマンド | 効果 |
|---|---|
| `agy models` | 使えるモデルの一覧 |
| `agy --model "モデル名"` | モデルを指定して起動 |

起動中に使えるコマンド（先頭に `/`）：

| コマンド | 効果 |
|---|---|
| `/model` | 今使っているモデルを確認 |
| `/usage` | 残り利用枠を確認 |
| `/quit` | 終了 |

> ⚠️ **Gemini Flash と Gemini Pro は同じ枠を共有します。** Pro を大量に使うと Flash の枠も減るので、
> 基本は Flash のまま進めてください。枠は `/usage` で確認できます。

---

## 安全に使うためのルール

- **AIに任せきりにしない**：変更内容を見る → アプリを動かす → 問題なければ次へ、を繰り返す
- **一度に大きすぎるお願いをしない**：「①投稿一覧を作る→確認→②投稿作成画面→確認」のように小さく進める
- **こまめに `git commit` する**：大きな変更の前に一度コミットしておくと、AIが壊しても戻せる
- **秘密情報を貼らない**：APIキーやパスワードはAIへの入力欄に貼らない（`.env` を使う）
- **`agy --dangerously-skip-permissions` は使わない**：確認なしにファイル操作が進むモードで、ハッカソンでは禁止

---

## 困ったときは

| 症状 | 対処 |
|---|---|
| `agy` が動かない | `agy --version` を確認。ダメなら VS Code を閉じて開き直す |
| 使えなくなった／応答が遅い | `/usage` で残り枠を確認 |
| Proになっている | `/quit` → `agy models` でFlashの正式名を確認 → `agy --model "その名前"` で再起動 |
| それでも分からない | 運営に声をかけてください |

---

## ゴール

AI に全部やらせることが目的ではありません。**作りたいものを伝える → 動かす → 直す**、
というバイブコーディングの流れを体験することが目的です。まずは動くものを作ることを優先しましょう。
